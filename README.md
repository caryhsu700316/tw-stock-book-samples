# 《讓數據替你選股》— 書中範例程式碼

這個資料夾收錄了書中各章「動手做做看」單元的**超小型可執行範例**。

每個範例都刻意做得很小，只示範該章最核心的一個觀念，讓你能在自己的電腦上跑起來、看到結果。書中只節錄了部分程式碼，這裡才是**完整、可直接執行**的版本。

> 完整的生產級系統（80+ 張資料表、70+ 個因子、機器學習與深度學習模型、自動排程等）不在此範例集合中。本資料夾的目的是「最小可重現」，幫助你理解書中觀念，而不是直接拿去交易。

## 目錄對照

| 資料夾 | 對應章節 | 主題 |
|--------|----------|------|
| `ch02_crawler` | 第二章 | 用爬蟲從證交所抓股票日成交資料 |
| `ch03_kline` | 第三章 | 讓程式看懂 K 線：辨識三種經典型態 |
| `ch04_factor` | 第四章 | 多因子投票：把幾個指標加權成一個總分 |
| `ch05_regime` | 第五章 | 判斷市場環境：牛市、盤整還是熊市 |
| `ch06_ml` | 第六章 | 最簡單的機器學習：用隨機森林排序股票 |
| `ch09_ptt` | 第九章 | PTT 社群分析：統計看多看空的情緒 |
| `ch10_line` | 第十章 | 用 LINE Messaging API 把選股結果推到手機 |

## 環境需求

- Python 3.10 以上
- 安裝套件：

```
pip install -r requirements.txt
```

## 執行方式

每個範例都可以單獨執行，例如：

```
python ch02_crawler/fetch_stock.py
python ch03_kline/detect_kline.py
```

## 注意事項

1. 範例使用的證交所、PTT 等公開資料來源可能會調整格式或加上流量限制，若執行失敗多半與此有關，不影響觀念理解。
2. 抓取公開資料時請放慢頻率（範例已內建延遲），避免造成對方伺服器負擔。
3. 範例僅供學習，**不構成任何投資建議**。
